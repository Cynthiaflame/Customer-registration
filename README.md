# LaflameTrust Registration Form

This is a simple registration form project built with HTML and CSS. It is part of my frontend learning practice, focusing on form structure, styling, and responsive layout for different screen sizes.

## Project Overview

The page contains a create-account form for LaflameTrust. The form includes fields for full name, email address, phone number, date of birth, gender, password, and confirm password.

## What I Practiced

- Building a form with HTML
- Connecting an external CSS file
- Styling inputs, labels, buttons, and error messages
- Using `box-sizing: border-box` to control element width
- Making the form responsive on desktop and mobile screens
- Testing layout behavior on iPhone screen sizes

## Technologies Used

- HTML
- CSS

## How to View the Project

Open `index.html` in a web browser.
